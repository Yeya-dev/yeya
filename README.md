# 叶芽 / Yeya

叶芽是一款 AI 阅读与学习 App。从自己的书开始，让 AI 帮你理解、翻译与整理，再沿着建档、学习计划、理解、答题、复习和测验，把书里的内容学下去。

## AI 功能

12 个模块可单独开启或关闭，普通阅读与批注无需先配置 AI。

| 模块 | 用途 |
| --- | --- |
| 阅读问答 | 解释选中文字，围绕当前章节继续提问 |
| 双语阅读与翻译 | 原文下逐句显示译文，按需提前翻译下一章 |
| 导读与章节总结 | 读前看重点与问题，读后回顾内容 |
| 书籍分析与学习计划 | 分析书籍与阅读策略，生成和调整学习安排 |
| 理解自检与练习 | 检查理解，生成练习与批改反馈 |
| 书库助手 | 查找书籍，提出待审核的文件夹整理方案 |
| 统一记录整理 | 检索和归纳已保存记录，整理新笔记 |
| 智能设置 | 用文字或语音调整设置、了解 AI 用量，打开复杂配置入口 |
| 昨日总结 | 回顾昨天实际阅读与保存的记录 |
| 今日发现 | 从真实搜索结果中选取相关外部文章 |
| 自动长期记忆 | 提炼少量偏好与关注问题，辅助后续讲解；可关闭或清除 |
| 扫描页面识别 | 按需使用视觉模型辅助识别，默认关闭 |

AI 使用自己选择的模型服务和 API Key，提供按功能、服务和模型查看的 AI 用量账本。阅读器内还可用自然语言调整阅读与播报设置，按需联网查询外部资料并保留网页来源。启用时，相关内容会发往所选服务；模型输出应回到原文核对。

## 阅读器

- 导入 EPUB、PDF、TXT、Markdown、MOBI、AZW、AZW3，使用文件夹整理书库，恢复阅读位置。
- 调整可重排正文的字体、字号、行距、段距、页边距；自选颜色、背景图片与显示强度。
- 整页翻页、章内连续滚动、宽屏横屏双页、自动翻页、目录跳转、亮度与延迟熄屏；原版 PDF 保留自身版式，有可用文字时可切换重排阅读。
- 保存书签，使用高亮、划线、圈注与侧边线批注，逐条保留笔迹样式。
- 在统一记录里回看笔记、批注、AI 交互与理解检查，跳回原文出处，也可以编辑分享草稿并导出图片。

## 翻译与双语阅读

- 三种显示方式：原文、双语阅读、仅译文；双语阅读在原文下逐句显示对应译文。
- 自动中英互译，或指定简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语与俄语。
- 调整译文字号与不透明度，设置本书译文偏好和术语表，复核或重新翻译。
- 下一章提前翻译、蜂窝网络与省流设置、本机译文缓存；PDF 效果取决于可用正文和识别质量。

## 系统学习

独立阅读按自己的节奏读书；系统学习先确认目标和偏好，再沿着完整流程进行：

1. **建档**：分析书籍，确认学习方式、目标与偏好。
2. **学习计划**：建立整体学习阶段，根据每天可用时间安排今天。
3. **理解**：带着导读读原文，随读问答，用自己的话做理解自检。
4. **答题**：完成理解检查与练习，查看批改、解析和原文依据。
5. **复习**：按回忆情况反馈，更新掌握情况与下次复习时间。
6. **测验**：交卷后统一批改，筛选错题，并进入错题复习。

系统学习保留整体学习阶段，按自然日生成当天安排。后续计划参考真实完成情况，不把未完成的内容当成已经掌握。

## 听书：三种场景与三类声音

- **边读边听**：从当前可视位置连续朗读，也可只听选中文字、当前段落、本节原文或导读。
- **通勤与散步**：收起播报页或离开阅读器接着听，用锁屏控件控制播放与切换章节。
- **睡前与休息**：15 / 30 / 60 分钟或自定义定时关闭，保留当前句和阅读位置。

连续朗读从当前阅读位置开始，跨章继续。播报模式提供播放控制、章节跳转、语速与发音人选择、锁屏控制和定时关闭。

- **系统语音**：使用设备已有的声音，无需语音 API。
- **离线声音包**：在语音市场选择「叶芽适配语音包」，按需下载安装后在本机合成，支持 Kokoro、VITS、Matcha、Kitten 等家族。
- **在线语音服务**：提供 Edge、Azure、ElevenLabs、Fish Audio、OpenAI 兼容接口等接入，在语音市场配置、测试与试听。

在线服务需要联网；各服务的可用性、授权和费用以其规则为准。更多细节见[听书说明](https://yeya-dev.github.io/yeya/guide.html#listening)。

## 更多功能与数据说明

支持文件、其他 App、局域网和已连接网盘导入，也提供阅读回顾、统一记录整理与主屏幕小组件。

书籍与记录保存在本机。AI、在线朗读、外部搜索、网盘与可选同步各有数据传输，使用前请核对设置和服务规则，见[数据与联网说明](https://yeya-dev.github.io/yeya/guide.html#data)。
