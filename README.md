# 页芽 Yeya

**让每一页，长成你的知识。**

页芽 Yeya 是一款从自己的书开始的 iOS 阅读 App，把阅读、翻译、听书、随读问答与理解记录连在一起。

这里是页芽 Yeya 的官方公开仓库，用于产品介绍、使用说明、问题反馈与更新公告。应用源码不在本仓库中公开。

## 当前状态

本页介绍**当前开发版本**的功能，不代表已经上架的版本承诺。目前没有经核验的公开下载地址；获取方式与正式版本更新将在确认后公布。

## 从原书开始，按自己的节奏阅读

- **阅读与整理**：导入自己的书，整理书库，继续上次的阅读；调整字体、主题与阅读外观。
- **翻译与听书**：双语阅读让原文与译文逐句衔接；连续朗读从阅读位置接着听。
- **随读问答**：围绕当前内容提问、解释难点，回到原文核对依据。
- **留下理解**：保存笔记、书签与不同样式的批注，再回看阅读中留下的想法。
- **选择学习方式**：独立阅读，或确认目标与偏好后进行系统学习；系统学习按日安排。

AI 功能需要自行配置模型服务，可按需开启。使用时，相关内容会发送给所选服务；部分朗读方式也使用在线服务。具体行为请参阅[用户说明](https://yeya-dev.github.io/yeya/guide.html)，并确认你所选服务的规则。
