用户说明

从导入一本书开始，了解阅读、AI 和学习功能怎么配合使用。这份说明对应当前开发版本，公开获取方式将在确认后公布。

01 · 书籍导入与书库

在书库选择导入，选取你有权使用的文件。也可以从其他 App 打开文件、通过局域网传书，或从已连接的网盘导入。支持 EPUB、PDF、TXT、Markdown、MOBI、AZW 和 AZW3；文件结构、加密或内容可提取情况会影响能否正常阅读。

导入后可以直接打开原书，不要求先分析整本书。退出再进入，会恢复已保存的阅读位置。书库文件夹用于整理书籍，不移动原书文件；一本书只归属一个文件夹。

网盘与 WebDAV 连接分别管理。选择服务并完成其要求的认证后浏览目录、下载导入；各账号的连接和凭据相互独立。

02 · 阅读外观

在阅读器顶部打开阅读设置，调整字体、字号、主题及正文外观，选择适合自己的翻页或滚动方式。可重排的正文会采用这些设置；原版 PDF 和固定版式页面保留自己的排版，不会被强行改成同一种字体。

通过目录跳转章节，或继续当前阅读位置。阅读时可以按需打开翻译、朗读和阅读问答，它们都围绕当前书籍内容使用。

03 · 书签、批注与统一记录

书签标记一个阅读位置，不要求选中文字。批注针对具体内容，可以选择高亮、划线、圈注或侧边线，并添加自己的说明。

高亮包括平直、手绘荧光笔、水彩、蜡笔、胶囊与渐变等样式；划线可以使用直线、波浪线、双横线、点线、虚线、铅笔线或钢笔线。每条批注保存自己的实际样式，后续修改预设不会改写旧批注。

在统一记录中回看笔记、批注、AI 交互和理解检查，使用筛选找到相关内容，再跳回出处。AI 整理模块可以检索和归纳已保存的记录，并保留来源；保存笔记本身不表示已经完成理解检查。

需要分享时，从记录选取内容，在本机编辑分享草稿并导出图片。分享文字的修改不写回原笔记；导出后由你决定是否通过系统分享。

04 · AI 设置与功能模块

先在设置里选择模型服务，填写自己的 API Key 和模型，再测试连接。AI 总开关及每个功能模块都可以分别控制。普通阅读、书签与批注不依赖模型配置。

模块能做什么
阅读问答解释选中文字，围绕当前章节提问、追问，回到原文核对依据。
双语阅读与翻译生成原文下的逐句译文，复核译文，按需提前翻译下一章。
导读与章节总结读前提出重点与问题，读后回顾章节内容。
书籍分析与学习计划分析书籍，提出阅读策略，确认偏好后生成与调整学习安排。
理解自检与练习生成问题，提供理解检查、练习、批改与反馈。
书库助手查找自己的书，提出文件夹整理方案，由你审核应用。
统一记录整理检索与归纳已经保存的记录，整理成新的笔记。
昨日总结回顾昨天实际显示过的原文与保存的阅读记录。
今日发现从真实搜索结果中选一篇与阅读有关的外部文章。
扫描页面识别按需使用视觉模型辅助页面识别，默认关闭。

每本书的导读、自检与练习还受本书的学习设置控制。模型输出可能有误，涉及原书的解释请回到原文核对。联网搜索结果是外部资料，不代替书中的依据。

05 · 双语阅读

配置模型后，在阅读器选择翻译设置与目标语言。译文逐句显示在原文下面，仍然沿着原书阅读。可以调整译文偏好，也可让下一章提前翻译；译文辅助理解，原书仍是核对的依据。

对于 PDF，正文提取与页面识别的质量会影响翻译效果。页面文字不确定时会提示识别可能有误；启用视觉辅助需要支持图片的模型及对应设置。

06 · 听书与语音市场

在阅读器打开播报模式，从当前阅读位置开始连续朗读。可以播放、暂停、快进一句、切换章节、调整语速与发音人。收起播报页或退出阅读器后，播放仍由 App 持有；锁屏控制可以切换章节。

选择声音来源

  • 系统语音：使用设备提供的发音人，无需配置语音 API，声音可用情况取决于设备安装内容。
  • 离线声音包：在语音市场按需下载，完成后在本机合成。支持 Kokoro、VITS、Matcha、Kitten 等家族；也能导入完整的自定义清单，一个模型文件地址不能代替全部依赖。
  • 在线语音服务：需要联网。语音市场提供供应商接入、凭据配置、连接测试与声音试听。

当前内置接入包括 Edge、Azure、ElevenLabs、Fish Audio、OpenAI 兼容语音接口、阿里云百炼、腾讯云、火山引擎、MiniMax、Deepgram、Amazon Polly、Google Cloud、智谱、百度和讯飞。每家的授权、可用地区、声音和计费方式不同，以服务自己的要求为准。Edge 朗读不要求单独填写 Key，但仍是在线服务。

定时关闭与失败处理

定时关闭提供 15、30、60 分钟和自定义时长。到期停止声音并保留当前句与阅读位置，之后可以继续；手动暂停不顺延计时。阅读器的延迟熄屏与听书定时关闭分别设置。

选定声音不可用时，可按条件从在线切换到本地或系统语音；界面会说明实际正在使用的声音。App 进程被终止后的持续播报不作保证。

07 · 独立阅读与系统学习

只想读书时，直接打开原书。独立阅读可以使用翻译、问答和章节总结，也可以为阅读进度安排节奏；不要求走完整的学习流程。

希望系统学习时，进入书籍分析与学习设置，确认学习目标、每天可用时间和偏好。书籍分析结果会提出建议，最终采用的学习方式由你确认。

  1. 分析与确认：了解书籍内容，确定目标与学习范围。
  2. 生成今日安排：保留整体学习阶段，根据原书顺序、时间预算和真实完成情况安排今天。
  3. 导读与原文：带着问题阅读，使用翻译、批注、问答和朗读辅助。
  4. 理解检查与练习：完整范围读完后检查理解，按本书设置进行自检或练习，并查看反馈。
  5. 复习与调整：保存学习结果，安排需要回看的内容，后续计划参考已保存的理解情况。

系统学习只生成当天的安排。同一天可以继续当前安排，下一自然日再生成新的今日计划。未完成内容不算已经消耗或掌握，也不会机械堆成今天的逾期欠账。生成失败时保留已有计划，可以重试。

08 · 数据与联网

导入的书、阅读位置与记录保存在本机。AI 功能会把完成请求所需的相关内容发送给你选择的模型服务；在线朗读会连接语音服务，今日发现会使用外部搜索。网盘导入与可选的数据同步另有连接和传输。

使用前，先确认自己的选择。

核对服务规则、书籍内容权限和启用的功能。不要把 API Key、密码或 Token 写进笔记、截图或公开反馈。完整数据处理说明请阅读隐私政策，并核对所选第三方服务条款。

主屏幕小组件读取本机导出的阅读和记录展示数据，不发起 AI 请求。
