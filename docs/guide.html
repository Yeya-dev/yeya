01 · 书籍导入与书库

在书库选择导入，选取你有权使用的文件。也可以从其他 App 打开文件、通过局域网传书，或从已连接的网盘导入。支持 EPUB、PDF、TXT、Markdown、MOBI、AZW 和 AZW3；文件结构、加密或能否提取文字会影响阅读效果。

导入后可以直接打开原书，先读，再决定是否分析这本书。退出再进入，会恢复已保存的阅读位置。书库文件夹用于整理书籍，原书文件仍保存在原处；一本书只归属一个文件夹。

网盘与 WebDAV 连接分别管理。选好服务并完成验证后，就能浏览目录、下载书籍并导入。各账号单独保存连接和凭据。

02 · 阅读外观

在阅读器顶部打开阅读设置，调整字体、字号、行距、段距、页边距与主题，选择整页翻页或章内连续滚动。整页模式在足够宽的横屏区域可显示双页，也能设置自动翻页间隔。这些排版设置适用于可重排正文；原版 PDF 和固定版式页面保留原有排版与字体。

阅读外观可以跟随主题，也可以自选正文与背景颜色，或从相册、文件中选择背景图片并调整显示强度。亮度与延迟熄屏也在阅读设置中调整。打开面板、选中文字或进入后台时，自动翻页会暂停。

PDF 可以按原版阅读，有可用文字时也可切换重排阅读。扫描页面先由本机识别文字，不确定的内容会提示；识别质量会影响后续翻译和问答。

通过目录跳转章节，或继续当前阅读位置。读书时，可以打开翻译、朗读或阅读问答，处理当前书里的内容。

03 · 书签、批注与统一记录

书签标记阅读位置，不用先选中文字。批注用来标记具体内容，可以选择高亮、划线、圈注或侧边线，并添加自己的说明。

高亮包括平直、手绘荧光笔、水彩、蜡笔、胶囊与渐变等样式；划线可以使用直线、波浪线、双横线、点线、虚线、铅笔线或钢笔线。每条批注保留当时的样式，修改预设后，旧批注保持原样。

在统一记录中筛选和回看笔记、批注、AI 交互与理解检查，再跳回出处。也可以请 AI 查找、归纳已保存的记录，整理后仍保留来源。理解检查需要单独完成，保存笔记不算完成检查。

需要分享时，从记录中选取内容，在本机编辑分享草稿并导出图片。修改分享文字后，原笔记保持原样；导出后，可以自行选择是否通过系统分享。

04 · AI 设置与功能模块

先在设置里选择模型服务，填写自己的 API Key 和模型，再测试连接。AI 总开关及 12 个功能模块都可以分别控制。普通阅读、书签与批注不依赖模型配置。

模块能做什么
阅读问答解释选中文字，围绕当前章节提问、追问，回到原文核对依据。
双语阅读与翻译生成原文下的逐句译文，复核译文，按需提前翻译下一章。
导读与章节总结系统学习读前看重点和问题，独立阅读查看章节总结。
书籍分析与学习计划分析书籍并建议阅读方法，确认偏好后生成或调整学习计划。
理解自检与练习生成自检问题与练习，提供理解检查、批改反馈，配合复习与阶段测验。
书库助手查找自己的书，提出文件夹整理方案，由你审核应用。
统一记录整理检索与归纳已经保存的记录，整理成新的笔记。
智能设置在设置页打字或说话，查询或修改设置，也能询问 AI 用量；复杂配置通过卡片打开设置。
昨日总结回顾昨天实际显示过的原文与保存的阅读记录。
今日发现从搜索结果中选一篇与阅读有关的外部文章。
自动长期记忆从互动和阅读中记下少量讲解偏好、已有基础和关注问题，供后续讲解参考；可以关闭或清除。
扫描页面识别按需请支持图片的模型辅助识别页面，默认关闭。

问答、用量与外部资料

在阅读器里可以围绕当前书籍提问；书库、统一记录和智能设置也各有 AI 入口。阅读问答需要查外部资料时，网页结果会注明来源。想改字体、间距、翻页、双语设置或控制播报，也可以直接告诉 AI。需要你手动选图片或配置复杂声音参数时，会打开相应设置。

在 AI 用量账本里，可以按功能、服务和模型查看请求，以及服务返回的 Token 用量；服务没有返回的用量不会按零计算。系统语音、离线声音包、本机文字识别和语音输入不消耗模型 API 用量。在线朗读与联网搜索需要分别配置，发送数据前也需要分别取得你的许可。

每本书的导读、自检和练习，还要看本书的学习设置是否开启。AI 回答可能有误，解释原书内容时，请回到原文核对。搜索得到的网页会标为外部资料，书里的依据仍需查看原文。

05 · 翻译与双语阅读

配置模型后，在阅读器打开翻译设置，选择目标语言与显示方式。支持三种方式：原文只显示原书并关闭翻译请求；双语阅读在原文下逐句显示对应译文；仅译文隐藏原文，用目标语言继续阅读。需要核对时可以切回原文或双语阅读。

语言、样式与术语

自动方向为中文译成英文、其他语言译成简体中文；也可指定简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语或俄语。调整译文字号和不透明度，设置本书译文偏好；在术语表中填写期望译法，供后续翻译参考。已有译文可复核，也可以重新翻译。

提前翻译与本机缓存

可启用下一章提前翻译，调整提前量、是否使用蜂窝网络与省流选项。完成的译文保存在本机，按目标语言和翻译配置区分；缓存可复用，但生成新译文仍需所选模型服务。

对于 PDF，正文提取与页面识别的质量会影响翻译效果。可用文字可以配合重排阅读；页面文字不确定时会提示识别可能有误。视觉辅助默认关闭，需支持图片的模型、对应开关与发送许可。

06 · 听书与语音市场

在阅读器打开播报模式，从当前阅读位置开始连续朗读。可以播放、暂停、快进一句、切换章节、调整语速与发音人。收起播报页或退出阅读器后仍能继续播放，锁屏时也可以切换章节。

三种听书场景

  • 边读边听：从当前可视处连续朗读，跨章继续；只想听一小段时，也可选择朗读选中文字、当前段落、本节原文或导读。
  • 通勤与散步：收起播报页或离开阅读器，继续播放；锁屏控件可暂停与切换章节。
  • 睡前与休息：设置定时关闭，到点暂停并保留阅读位置，之后接着听。

三类声音来源

  • 系统语音：使用设备提供的发音人，无需配置语音 API，可选声音取决于设备上已安装的系统声音。
  • 离线声音包：在语音市场选择「叶芽适配语音包」，按所选站点下载，完整校验与安装后在本机合成；安装完成后再选择启用。支持 Kokoro、VITS、Matcha、Kitten 等家族；也能导入完整的自定义声音包清单，需要包含所有依赖，一个模型文件地址还不够。
  • 在线语音服务：需要联网。可以在语音市场选择服务、填写凭据、测试连接和试听声音。

当前内置接入包括 Edge、Azure、ElevenLabs、Fish Audio、OpenAI 兼容语音接口、阿里云百炼、腾讯云、火山引擎、MiniMax、Deepgram、Amazon Polly、Google Cloud、智谱、百度和讯飞。每家的授权、可用地区、声音和计费方式不同，以服务自己的要求为准。Edge 朗读无需单独填写 Key，使用时也要联网。

定时关闭与声音不可用时的处理

定时关闭提供 15、30、60 分钟和自定义时长。到期停止声音并保留当前句与阅读位置，之后可以继续；手动暂停不顺延计时。阅读器的延迟熄屏与听书定时关闭分别设置。

选定声音不可用时，可按条件从在线切换到本地或系统语音；界面会显示实际使用的声音。App 进程结束后，持续播报可能中断。

07 · 独立阅读与系统学习

只想读书时，直接打开原书。独立阅读可以使用翻译、问答和章节总结，也可以为阅读进度定一个计划，不必完成整套学习流程。

想系统学习时，进入书籍分析与学习设置，确认学习目标、每天可用时间和偏好。书籍分析会提出建议，采用哪种学习方式由你确认。

  1. 建档：进入分析与学习设置，了解书籍内容与推荐阅读方法，确认独立阅读或系统学习、目标和偏好。导入后可以先读，稍后再建档。
  2. 学习计划：确认每日可用时间，建立整体学习阶段，结合原书顺序、实际完成情况与掌握情况生成今日安排。
  3. 理解：带着导读的问题读原文，通过 AI 问答弄清难点，用自己的话完成理解自检。可以打字，也可以语音转文字后编辑确认；保存笔记本身不表示已经掌握。
  4. 答题：读完本次学习范围后，做理解检查与练习，提交选择或文字回答，再查看 AI 批改、解析与原文依据。需要时也能补充练习。
  5. 复习：进入复习，先回想再核对，按回忆情况反馈。复习结果会更新掌握情况与下次复习时间，未完成的复习可以继续。
  6. 测验：完成阶段测验，检查待答题后交卷，统一查看批改结果。可以只看错题、查看原文依据，再进入错题复习。

系统学习只生成当天的安排。同一天可以继续当前安排，第二天再生成新的今日计划。未完成的内容不计作已学或已掌握，也不会积成逾期任务。生成失败时保留已有计划，可以重试。

08 · 数据与联网

导入的书、阅读位置与记录保存在本机。使用 AI 时，完成请求所需的相关内容会发送给你选择的模型服务；在线朗读会连接语音服务，今日发现会使用外部搜索。从网盘导入书籍或开启数据同步时，也会发生数据传输。

联网服务与内容权限

使用前请核对服务规则、书籍内容权限和已开启的功能。不要把 API Key、密码或 Token 写进笔记、截图或公开反馈。完整数据处理说明请阅读隐私政策，并核对所选第三方服务条款。

主屏幕小组件读取本机保存的阅读和记录展示内容，不发起 AI 请求。
