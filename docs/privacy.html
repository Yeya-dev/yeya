1. 适用范围

页芽 Yeya 由张震开发与运营，本政策中的“我们”指张震。本政策说明页芽 Yeya 如何处理个人阅读与学习数据，以及你启用可选远端功能时的数据发送。浏览官网、访问外部链接和你选择的第三方服务，也受这些服务各自的隐私政策及条款约束。开发中的功能与实际发布版本可能不同，请以所用版本中可见的功能为准。

2. 本机内容

导入的书籍文件、书库分组、阅读位置、批注、笔记、学习记录、AI 对话及生成内容首先保存在你的设备。基础导入、阅读与本机记录无需注册页芽主账号，也不要求开启使用统计或向模型发送内容。

BYOK API Key、网盘访问令牌及 WebDAV 应用密码按用途保存在设备 Keychain；非秘密设置另存本机。凭据用于请求你选择的服务，不放入同步业务数据或应用使用事件。你主动提交给 AI 的文字若包含秘密，模型仍可能收到；请勿把密钥或密码写入问题、书籍或笔记。

3. 可选模型服务与页面图片

启用 AI 功能前，应用按接收方请求你的明确许可。模型请求可能包含你提交的问题、必要对话历史、所用功能需要的书籍正文、书名与作者、阅读事实、笔记、作答、设置或工具结果，用于阅读问答、翻译、学习内容生成、书库或记录整理等功能。今日发现只向模型发送有限书库与阅读事实；昨日总结可能使用实际已显示原文与已保存记录。已启用的自动生成和双语预取会在许可有效时发送相应内容。

页面图片采用独立许可；你主动使用扫描页面识别等功能时，可能发送页面图片及提示。拒绝图片许可不等于撤回文字许可。连接测试与能力探测发送测试内容；图像能力探测可能发送应用生成的测试图片。

请求直接从设备发往所选官方服务或自定义地址。相应凭据只用于该服务的鉴权。接收方能看到网络地址，可能按自己的条款记录、保留或处理请求；服务价格、部署区域、数据保留和训练选项取决于你选择的服务及账号配置。页芽无法保证所有自定义服务不保留数据或不用于训练；使用前请核对该服务政策。请仅选择你信任并具备适当数据保护措施的服务。

4. 朗读、语音输入与联网搜索

系统语音与已安装的本地声音包在设备上合成，不为合成向在线服务发送正文。下载声音包时，下载服务会收到下载请求和网络地址；这是模型文件下载，与发送书籍正文分别处理。

在线朗读在取得许可后发送待朗读文字、发音人、语速等参数，必要时使用你填写的服务凭据。Edge 朗读也是在线服务；连接测试、试听及声音查询同样可能联系相应服务。它们的处理、保留和费用遵循对应服务条款，拒绝在线许可后仍可使用可用的本地或系统声音。

语音输入由你主动开启并请求麦克风与语音识别权限，应用要求端侧识别。设备或语言不支持时可使用键盘。转录文字在设备上可编辑，之后由你发送的文字仍可能进入所选模型请求。

联网搜索单独取得许可后发送查询词给所选 Tavily 或 SearXNG 服务；查询可能根据你的问题、书名、作者或阅读事实生成。搜索服务可能将查询交给自己的搜索引擎。点击结果后访问的网站能够收到你的访问请求，并按其政策处理数据。

5. 网盘、同步与局域网传书

添加网盘或 WebDAV 连接时，你向相应服务授权访问自己内容，应用保存必要的连接资料和设备凭据。导入会请求所选目录与文件；移除连接阻止后续应用访问，但不删除第三方账号或云端文件。

数据同步默认关闭。你明确选择 iCloud 或可用的网盘/WebDAV 位置并许可后，书籍文件、阅读位置、笔记、AI 对话、学习内容及可同步设置可发送到该位置。自动同步会发送后续变化；删除也可能传播到其他设备。同步目的地、账号与权限由你控制，保留与删除规则同时受对应服务影响。移除连接或关闭同步不会自动删除云端副本。

Wi-Fi 传书由你主动开启，在局域网内接收文件，使用明文 HTTP。请只在可信网络中使用，并在完成后退出传书界面；同网络设备可能看到传输内容或尝试访问该入口。它不是端到端加密传输。

6. 使用统计

「帮助改进页芽」是独立的可选设置，默认关闭。使用统计启用需要当前应用隐私政策已明确同意、独立开关开启及当前构建允许上报。隐私核验尚未完成的正式构建不初始化统计。

允许统计的构建使用友盟 U-App。应用自定义事件限于固定页面访问、导入结果与有限文件格式、阅读器打开等，不传书名、书籍正文、笔记、对话、文件路径、错误正文或 API Key。友盟 SDK 还按厂商政策处理设备标识、设备/应用/网络信息等；不能将应用自定义事件的限制理解为 SDK 不收集其他信息。请阅读 友盟隐私政策。

关闭统计或撤回当前政策同意后，应用停止新增使用事件并通知 SDK 关闭统计；下次启动不初始化。不承诺即时取消 SDK 已发出的请求、删除其缓存或删除远端已收到的数据，也不补报关闭期间的应用事件。最终启用统计的发布版本，应在发布前核实并披露厂商实际数据种类、用途与处理配置。

7. 控制、保留与删除

在「设置 → 数据与隐私 → 远端数据发送」查看或撤回各类许可。填写 Key、开启功能开关、完成介绍或同意使用统计不代替远端发送许可。新的接收来源或说明版本需要重新确认。撤回后应用不再发起未经授权的新请求，并停止当前模型运行和朗读；已发送的数据无法收回，远端删除请联系所选服务。

关闭功能不会自动删除已保存的阅读与学习内容。你可删除具体书籍或记录，或使用「删除所有本地数据」；凭据在相应服务设置中另行移除。启用同步时，本地删除可能同步到其他设备。卸载前请按需备份；本机副本、系统备份与云端副本的生命周期并不相同。

本机业务内容一般由你保存至主动删除。第三方服务的数据保留期限、删除方法、处理区域及账号权利应以该服务当前政策与设置为准。页芽没有权限替你删除第三方账号或保证其远端副本立即消失。

8. 分享、官网与支持

分享图片在本机生成，由你主动调用系统分享或保存到相册。你选择的接收应用或平台适用自己的条款；系统分享完成不代表内容已在平台公开发布。主屏幕小组件读取本机 App Group 的有限阅读与记录投影，不发起模型请求，可能在桌面呈现书名或记录内容。

官网由 GitHub Pages 提供静态页面，不自行加入统计、登录或支付。GitHub 作为托管服务可能按其政策记录访问和网络信息。公开反馈通过 GitHub Issues；提交需要 GitHub 登录，Issue、用户名、评论与附件公开可见。请勿在那里提交私人书籍、API Key、密码、个人数据或敏感日志。

隐私咨询、个人数据请求和其他不适合公开的材料，请发送至 1169458576@qq.com。只提供处理请求需要的最少信息；我们会核对请求并说明可操作的范围。

数据用途、接收方或重要控制发生变化时，政策及发送说明会更新，必要时重新请求同意。有关本政策的问题，请联系张震，邮箱：1169458576@qq.com。
