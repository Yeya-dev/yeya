隐私咨询与个人数据请求

涉及隐私、个人数据请求，或材料不适合公开时，请发邮件联系叶芽的开发与运营者张震：1169458576@qq.com。只需提供处理请求所需的信息，请勿发送 API Key、密码或 Token。

本机数据、可选联网服务，以及撤回同意和删除数据的方法，见隐私政策。GitHub Issue 会公开显示，请通过邮件处理个人数据问题。

上传附件前，遮住私人内容

GitHub Issues 是公开区域。请勿上传 API Key、密码、Token、私人书籍或含个人数据的日志；截图与附件请先移除或遮住敏感内容。

先描述操作和现象，只附上排查问题所需的内容。如果问题只在某本私人书籍中出现，可以自编一段短示例来说明，避免公开原文件。

查看已有反馈

你遇到的问题可能已经有人提过。可以先查看已有反馈，或回到用户说明确认操作方法。

官网和公开反馈可以直接浏览，提交 Issue 需要登录 GitHub。修复进展会注明开发或发布状态；是否已经收到修复，请以确认发布的版本信息为准。
